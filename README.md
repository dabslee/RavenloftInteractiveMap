# Castle Ravenloft HTML Map Generator

This project generates a set of interconnected HTML pages representing the map of Castle Ravenloft from the Dungeons & Dragons module *Curse of Strahd*.

## Project Structure

-   `Castle Ravenloft.md`: The primary source of room descriptions and connections, written in Markdown.
-   `parse_markdown.py`: This script reads `Castle Ravenloft.md`, parses its content, and extracts room information (ID, name, description, connections, coordinates). It then saves this structured data into `parsed_rooms.json`.
-   `castle_data.py`: This script loads the room data from `parsed_rooms.json`.
-   `generate_html.py`: This script takes the data loaded by `castle_data.py` and generates individual HTML files for each room in the `html_map/` directory. It also creates a minimap for navigation within each room's HTML page.
-   `html_map/`: This directory contains the generated HTML files for each room and the `style.css` file for theming.
-   `images/`: This directory will store images referenced in `Castle Ravenloft.md` and any additional images used for the map rooms.
-   `parsed_rooms.json`: A JSON file containing the structured data of all rooms, generated by `parse_markdown.py`.

## How it Works

1.  **Parsing Markdown**: `parse_markdown.py` is executed first. It processes `Castle Ravenloft.md` to identify room sections, extract details like room names, descriptions, and connections to other rooms. It also assigns coordinates to each room based on its section in the markdown. The output is `parsed_rooms.json`.
2.  **Loading Data**: `castle_data.py` is responsible for loading the structured room data from `parsed_rooms.json`. This makes the data accessible to the HTML generation script.
3.  **Generating HTML**: `generate_html.py` uses the loaded room data. For each room, it creates an HTML file in the `html_map/` directory. Each HTML page includes:
    *   The room's name and description.
    *   Links to connected rooms.
    *   A minimap showing the room's location relative to other rooms.
    *   Styling is provided by `html_map/style.css`.
    *   Images for rooms will be sourced from the `images/` directory.

## Usage

1.  Ensure `Castle Ravenloft.md` is up-to-date with the desired room information.
2.  Run `python parse_markdown.py` to generate/update `parsed_rooms.json`.
3.  Run `python generate_html.py` to generate/update the HTML files in `html_map/`.
4.  Open any `.html` file in `html_map/` in a web browser to explore Castle Ravenloft.

## Customization

-   **Styling**: Modify `html_map/style.css` to change the appearance of the HTML pages.
-   **Images**: Add or change images in the `images/` folder. Update references in `Castle Ravenloft.md` or `generate_html.py` as needed.
